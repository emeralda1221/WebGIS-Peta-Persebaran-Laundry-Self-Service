# Laundry Self-Service — Kabupaten Sleman

WebGIS Laundry Self-Service Kabupaten Sleman dengan istilah **Kecamatan** pada tampilan dan filter.

## File
- `index.html` — halaman utama WebGIS.
- `script.js` — JavaScript dan data 59 lokasi.
- `style.css` — CSS asli dari source WebGIS.
- `README.md` — dokumentasi.

## Label
Semua label dan referensi `Kapanewon` pada antarmuka telah diganti menjadi `Kecamatan`, termasuk:
- subtitle
- statistik jumlah Kecamatan
- filter/chip Kecamatan
- pesan hasil pencarian/filter
- variabel internal terkait filter

Data lokasi dan koordinat tetap sama seperti source asli.

## Cara menjalankan
1. Extract ZIP.
2. Simpan keempat file dalam satu folder.
3. Buka `index.html` atau jalankan melalui VS Code Live Server.
4. Internet diperlukan untuk layanan peta dan font eksternal.
